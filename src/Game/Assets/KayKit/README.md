# Selected free KayKit assets

These files are vendored for offline import and export. All three selected packs are CC0; license texts accompany each subset. `manifest.json` records official source paths, pinned Git commits or original archive members, retrieval date, and SHA-256 checksums. No paid tiers, third-party mirrors or runtime downloads are used.

- [Medieval Hexagon Pack 1.0](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0): blue mine, barracks, windmill (labeled Farm), home, tower and tree; shared texture. The hexagonal theme does not change the square 3×3 logical board. Home/tower and decorations occupy no building slot.
- [Prototype Bits 1.0](https://github.com/KayKit-Game-Assets/KayKit-Prototype-Bits-1.0): Dummy Base for troops, Can A for food prop and Cube Prototype Small for available markers, plus shared texture. Soldiers have blue markers and enemies red markers; labels show S/E and remaining health. No character animations are needed.
- [Resource Bits 1.0 Free](https://kaylousberg.itch.io/resource-bits): Gold Bars, its buffer and texture, acquired from the official Free download (upload 13266824). This is a gold prop, not the paid coin/food extras. Archive checksum is recorded in the manifest.

Models are normalized to fit their slot and use their original imported materials. Only graphical clients instantiate them. Headless clients and stripped dedicated-server exports operate entirely from numerical state.
